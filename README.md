# ⚡ autoreger

Универсальный userscript для [Tampermonkey](https://www.tampermonkey.net/): автозаполнение форм регистрации на **любом сайте**. Логин с автоинкрементом числа, пароль в оба поля, клик по кнопке регистрации одной кнопкой и накопление результатов в окне «Отдача» с копированием в один клик.

![Tampermonkey](https://img.shields.io/badge/Tampermonkey-userscript-00485B?logo=tampermonkey&logoColor=white)
![Version](https://img.shields.io/badge/version-5.0-4f46e5)
![License](https://img.shields.io/badge/license-MIT-16a34a)

Скрипт не привязан к конкретному сайту. Всё, что нужно адаптировать, — селекторы полей, кнопки и ссылки в блоке **CONFIG** в начале файла.

---

## 📦 Установка

1. Установи расширение **Tampermonkey** (Chrome / Firefox / Edge).
2. Tampermonkey → **Создать новый скрипт**.
3. Удали шаблон и вставь содержимое [`autoreger.user.js`](autoreger.user.js).
4. Сохрани (`Ctrl+S`).
5. Открой нужную страницу — панель появится справа сверху.

По умолчанию скрипт работает на всех сайтах (`@match *://*/*`). Чтобы ограничить его одним сайтом, замени строку в шапке:

```javascript
// @match        https://example.com/*
```

## 🔧 Настройка под свой сайт

Открой блок **CONFIG** в начале скрипта — это единственное место, которое нужно менять.

| Параметр | За что отвечает | Пример |
|---|---|---|
| `loginSelectors` | Поле логина/email (пробуются по очереди) | `input[type="email"]`, `input[name="email"]` |
| `passwordSelector` | Поля пароля (заполняются все найденные) | `input[type="password"]` |
| `submitSelector` | Кнопка отправки формы | `button[type="submit"]` |
| `submitText` | Запасной поиск кнопки по тексту | `/create account\|sign up\|register/i` |
| `signupLinkSelectors` | Ссылка на страницу регистрации | `a[href*="signup"]` |
| `signupLinkText` | Запасной поиск ссылки по тексту | `/create an account\|sign up/i` |
| `signupPagePattern` | Как понять, что ты уже на регистрации | `/sign[-_]?up\|register/i` |
| `signupUrl` | Запасной прямой адрес регистрации | `https://example.com/signup` |
| `submitDelay` | Пауза перед кликом по кнопке (мс) | `300` |

**Как найти селекторы:** на целевой странице кликни правой кнопкой по полю → «Посмотреть код» (Inspect) → в подсветившемся элементе возьми `type`, `name`, `id` или класс. Например, для `<input name="user_email">` подойдёт `input[name="user_email"]`.

Чаще всего достаточно поменять `loginSelectors`, `submitSelector` и `signupLinkSelectors` — остальное уже универсально.

## 🚀 Использование

В поле панели введи **два значения столбиком** — строка 1 логин, строка 2 пароль:

```
login320@mail.ru
mypassword123
```

Жми **«Создать аккаунт →»** — скрипт:

1. вставит логин в поле логина;
2. вставит пароль во все поля пароля (пароль + повтор);
3. через паузу кликнет по кнопке регистрации на сайте;
4. запишет пару `логин + пароль` в «Отдачу»;
5. увеличит число в логине на 1 — поле само станет `login321@mail.ru`.

Дальше — просто жми кнопку снова. Если после регистрации тебя перекинуло на страницу входа, включи **авто-возврат** — скрипт сам кликнет по ссылке регистрации и вернёт на форму.

## 🎛 Кнопки панели

| Элемент | Что делает |
|---|---|
| **–** | Скрыть панель на этом сайте (останется бейдж «⚡ autoreger» внизу справа) |
| **Вставить логин** | Вставляет текущий логин, число +1 |
| **↺** | Возвращает логин к последнему введённому вручную значению |
| **Вставить пароль** | Вставляет пароль из 2-й строки во все поля пароля |
| **Вставить всё** | Логин + пароль, **без** отправки формы |
| **Создать аккаунт →** | Логин + пароль + клик по кнопке + запись в отдачу |
| **авто-возврат** | Автоматически кликает ссылку регистрации, когда она появляется |
| **Копировать** | Копирует всю отдачу в буфер обмена |
| **✕** | Очищает отдачу (с подтверждением) |

Под полем две подсказки: `→ вставится: …` — что уйдёт в форму следующим кликом, `↺ сброс: …` — что вернёт кнопка сброса.

## 🧠 Логика инкремента

Увеличивается **последняя группа цифр до `@`**:

| Было | Стало |
|---|---|
| `login317@mail.ru` | `login318@mail.ru` |
| `user007@mail.ru` | `user008@mail.ru` (ведущие нули сохраняются) |
| `user12test99@mail.ru` | `user12test100@mail.ru` |
| `login@mail2.ru` | `login1@mail2.ru` (цифры домена не трогаются) |
| `login@mail.ru` (цифр нет) | `login1@mail.ru` → `login2@mail.ru` |

- Правишь **2-ю строку** (пароль) — счётчик не сбрасывается.
- Правишь **1-ю строку** — отсчёт начинается заново с введённого значения, оно же запоминается для `↺`.

## 📋 Отдача

Каждый успешный клик по кнопке регистрации дописывает в окно пару значений:

```
login320@mail.ru
mypassword123

login321@mail.ru
mypassword123

login322@mail.ru
mypassword123
```

- Запись попадает в отдачу **только после реального клика** по кнопке сайта.
- В запись идут именно те значения, которые ушли в форму.
- В заголовке окна — счётчик аккаунтов.
- Отдача переживает перезагрузки и переходы между страницами. Очистка — только через `✕`.

## ⚙️ Технические детали

- **Совместимость с React/Vue**: значения ставятся через нативный сеттер `HTMLInputElement.prototype.value` + события `input`/`change` — фреймворк «видит» вставленные значения.
- **SPA-устойчивость**: если приложение перерисовывает страницу и сносит панель — она возвращается автоматически.
- **Защита от двойного клика** по «Создать аккаунт».
- **Хранение**: `GM_getValue`/`GM_setValue`. Логин/пароль/отдача — общие; авто-возврат и видимость панели — свои для каждого домена.

> ⚠️ Хранилище Tampermonkey привязано к `@name` + `@namespace`. При переименовании скрипта сохранённые данные и отдача начнутся с чистого листа — скопируй отдачу заранее. Пароль хранится в хранилище расширения в открытом виде.
