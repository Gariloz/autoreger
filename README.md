# ⚡ autoreger

Userscript для [Tampermonkey](https://www.tampermonkey.net/), который автоматизирует рутину на странице регистрации `app.trysixth.com`: логин с автоинкрементом числа, пароль в оба поля, клик по **Create account** одной кнопкой и накопление результатов в окне «Отдача» с копированием в один клик.

## 📦 Установка

1. Установи расширение **Tampermonkey** ([Chrome](https://chrome.google.com/webstore/detail/tampermonkey/dhdgffkkebhmkfjojejmpbldmpobfkfo) / [Firefox](https://addons.mozilla.org/firefox/addon/tampermonkey/) / Edge).
2. Tampermonkey → **Создать новый скрипт**.
3. Удали шаблон и вставь содержимое [`autoreger.user.js`](autoreger.user.js).
4. Сохрани (`Ctrl+S`).
5. Открой `https://app.trysixth.com/vscode/signup` — панель появится справа сверху.

> Скрипт работает на всех страницах `https://app.trysixth.com/*` (регистрация, логин и т.д.).

## 🚀 Использование

В поле панели введи **два значения столбиком** — строка 1 логин, строка 2 пароль:

```
login320@mail.ru
mypassword123
```

Жми **«Создать аккаунт →»** — скрипт:

1. вставит логин в поле email;
2. вставит пароль в оба поля (пароль + повтор);
3. через 300 мс кликнет по настоящей кнопке **Create account** на сайте;
4. запишет пару `логин + пароль` в «Отдачу»;
5. увеличит число в логине на 1 — поле само станет `login321@mail.ru`.

Дальше — просто жми кнопку снова. Если после регистрации тебя перекинуло на страницу логина, **авто-возврат** сам кликнет по ссылке «Create an account →» и вернёт на форму.

## 🎛 Кнопки панели

| Элемент | Что делает |
|---|---|
| **Вставить логин** | Вставляет текущий логин в поле email, число +1 |
| **↺** | Возвращает логин к последнему введённому вручную значению |
| **Вставить пароль** | Вставляет пароль из 2-й строки в оба поля пароля |
| **Вставить всё** | Логин + пароль, **без** отправки формы |
| **Создать аккаунт →** | Логин + пароль + клик по Create account + запись в отдачу |
| **авто-возврат** | Автоматически кликает «Create an account →», когда ссылка появляется на странице |
| **Копировать** | Копирует всю отдачу в буфер обмена |
| **✕** | Очищает отдачу (с подтверждением) |

Под полем две подсказки: `→ вставится: …` — что уйдёт в форму следующим кликом, `↺ сброс: …` — что вернёт кнопка сброса.

## 🧠 Логика инкремента

Увеличивается **последняя группа цифр до `@`**:

| Было | Стало |
|---|---|
| `login317@mail.ru` | `login318@mail.ru` |
| `user007@mail.ru` | `user008@mail.ru` (ведущие нули сохраняются) |
| `user12test99@mail.ru` | `user12test100@mail.ru` |
| `login@mail2.ru` | `login1@mail2.ru` (цифры домена не трогаются) |
| `login@mail.ru` (цифр нет) | `login1@mail.ru` → `login2@mail.ru` |

- Правишь **2-ю строку** (пароль) — счётчик не сбрасывается.
- Правишь **1-ю строку** — отсчёт начинается заново с введённого значения, оно же запоминается для `↺`.

## 📋 Отдача

Каждый успешный клик по Create account дописывает в окно пару значений:

```
login320@mail.ru
mypassword123

login321@mail.ru
mypassword123

login322@mail.ru
mypassword123
```

- Запись попадает в отдачу **только после реального клика** по кнопке сайта (если кнопка не найдена или неактивна — записи не будет).
- В запись идут именно те значения, которые ушли в форму.
- В заголовке окна — счётчик аккаунтов.
- Отдача переживает перезагрузки и переходы между страницами. Очистка — только через `✕`.

## ⚙️ Технические детали

- **React-совместимость**: значения ставятся через нативный сеттер `HTMLInputElement.prototype.value` + события `input`/`change` — React «видит» вставленные значения, и форма не слетает при отправке.
- **Поиск кнопки отправки**: `button[type="submit"].sd-btn-accent`, запасной поиск по тексту `Create account`.
- **SPA-устойчивость**: если приложение перерисовывает страницу и сносит панель — она возвращается автоматически.
- **Защита от двойного клика** по «Создать аккаунт».
- **Хранение**: `GM_getValue`/`GM_setValue` (ключи: `template`, `current`, `password`, `log`, `autoNav`).

> ⚠️ Хранилище Tampermonkey привязано к `@name` + `@namespace`. При переименовании скрипта сохранённые данные и отдача начнутся с чистого листа — скопируй отдачу заранее. Пароль хранится в хранилище расширения в открытом виде.
